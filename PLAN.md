# PLAN: closing the open issues

Base: `claude/festive-wozniak-895m6p` @ `19a53f5` (455 tests passing).

Every issue below was reproduced by a read-only investigation. The reproduction scripts and their captured outputs are in [`repro/`](repro/). File names are prefixed with the issue ID, and paths and `file:line` refer to the base commit. Scripts that need a bench database or a tau-bench clone say so in their header. Run them from the repo root with the package installed (`pip install -e . -e bench`).

## Global invariants for every change

These hold for every merge:

1. **Tests.** `python3 -m pytest -q tests` is green and `python3 -m pyflakes src bench/src tests` is clean.
2. **Tests before fixes.** Each fix lands with the acceptance tests listed for its issue. Those tests fail on the base and pass after the fix.
3. **Success.**
   - Sim: over 200 tasks on each of seeds 0–5, `treejit` and `treejit+ok` succeed at least as often as `baseline` on the same seed.
   - tau-bench, once the runner exists: the same holds for reward.
4. **Safety.** Nothing that is not read-only replays without approval. No commit point replays without approval plus extra evidence. A value filled in by the model (T3) can't change a call's commit status.
5. **Scope.** An implementer changes only the files its workstream owns (see below). A change needed elsewhere goes in the final report.

### Accepted boundaries (not fixed, documented)

- **Tool execution isn't visible** at the model-API boundary. treejit backtracks its policy, not the world. The fix is a separate MCP-side proxy (out of scope).
- **Real-model validation is blocked** here because there is no API key. W9 makes `--agent claude` ready to run.
- The final answer always costs one full call.
